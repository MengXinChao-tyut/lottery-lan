# 局域网现场扫码抽奖设计

用户已于 2026-10-11 确认此方案并要求实现，参加人数约十几人，来宾与 Windows 抽奖电脑连接同一 Wi-Fi。

## 已确认的体验

- 电脑本地运行，自动生成指向局域网地址的报名二维码；来宾手机无需安装应用。
- 来宾填写姓名和中国大陆手机号，同一活动手机号唯一；重复提交给出明确提示。手机号未使用短信验证码验证所有权。
- 电脑管理页每两秒更新名单和人数，支持配置活动标题、奖项、名额与每轮人数；可删除报名错误的人员。
- 主持人关闭报名后锁定人员；原有 Three.js 3D 球体展示保留，中奖者默认不再参加其它奖项。
- 服务器选择并立即保存中奖结果，重试同一请求不会再次开奖；刷新/重启均恢复报名与结果。
- 电脑可导出报名名单、中奖记录为 Excel；大屏只显示姓名、报名编号、脱敏手机号。
- 管理操作与完整手机号只允许本机 localhost/127.0.0.1 访问；局域网手机只可以报名。
- 数据统一保存到 server/data/lan-event.json，运行时数据不提交版本库，也不打包测试名单。

## 边界

使用原项目独立副本与 feat/lan-signup 分支；保留 MIT 许可证和上游归属。只交付本地程序，不发布云网站、不修改用户已有项目、不上传来宾数据。共享 Wi-Fi 必须允许设备互访；防火墙放行留给 Windows 的网络提示或操作说明，不自动修改系统防火墙。

## 架构

Vue 3 手机报名页和电脑管理页共用单一 Express 服务；生产时从 product/dist 提供前端、局域网监听 0.0.0.0。浏览器内的原有动画只是展示；后台为名单和结果的唯一来源。小规模单进程使用同步原子替换 JSON，写入失败时不修改内存，不返回成功。报名关闭时保存 ID 快照，开奖只能从快照中未中奖人员选择。

## 验收

测试覆盖手机号规范化及唯一性、同时报名、关闭报名、名单锁定、并发/重试开奖、防重复中奖、奖品名额、持久化/重启、完整手机号访问限制、旧接口不能绕过、恶意姓名安全显示及导出、新活动二维码失效。浏览器验证手机布局、真实 QR 内容、名单更新、开奖和刷新恢复。生产构建与可复制 Windows 启动包验证通过后交付。
